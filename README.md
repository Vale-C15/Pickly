# ✨ Pickly

Pickly es una aplicación web diseñada para guardar actividades, ideas o tareas según el tiempo disponible y la categoría, ayudando a decidir qué hacer cuando tienes tiempo libre pero no sabes en qué usarlo.

La app incluye un sistema de filtros y una ruleta interactiva para elegir actividades de forma dinámica y visual.

---

## 🌐 Demo

🔗 https://picklyapp.vercel.app/

---

## 🧠 Problema que busca resolver

Muchas veces:
- tenemos tiempo libre,
- queremos hacer algo productivo o divertido,
- pero no sabemos qué elegir.

Pickly busca resolver esa indecisión permitiendo:
- guardar actividades fácilmente,
- organizarlas por categoría y duración,
- y usar una ruleta para escoger una opción al azar según filtros personalizados.

## 🎨 Diseño y UX

Pickly fue diseñada con un enfoque:
- minimalista,
- cálido,
- visual,
- y más cercano a una app personal que a una herramienta corporativa.

La interfaz utiliza:
- categorías con colores dinámicos,
- microinteracciones,
- tarjetas estilo “cozy productivity”,
- y una experiencia centrada en reducir la fricción al decidir qué hacer.

## ⚙️ Instalación local

Clona el repositorio:

```bash
git clone https://github.com/Vale-C15/pickly.git
```

Instala dependencias:

```bash
npm install
```

Ejecuta el entorno de desarrollo:

```bash
npm run dev
```
